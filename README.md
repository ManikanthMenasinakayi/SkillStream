## About the Project
SkillStream is designed to bridge the gap between "randomly watching tutorials" and "structured learning." While YouTube hosts the world's best educational content, it lacks the structure and satisfaction of a paid course.

This platform allows users to:

Focus: Deep-work environment with zero YouTube recommendations or comments.

Track: Real-time progress bars and "Satisfaction of Completion" triggers.

Master: Domain-specific roadmaps (Web Dev, Data Science, etc.) curated by the community.


# How to Raise a Pull Request (PR) for SkillStream

To maintain code quality and our minimalist aesthetic, all changes must follow this workflow.

## 🚀 The Step-by-Step Process

### 1. Sync Your Local Repository
Before starting, ensure your local `main` branch is up to date:

=>git checkout main
=>git pull origin main

### 2. Create a Feature Branch
# Never work directly on main. Create a descriptive branch:
=>git checkout -b feature/your-feature-name

### 3. Make Your Changes
# Build your component or add data. Ensure your code follows the project's styling and structure.

### 4. Push and Raise the PR
# Push your branch to GitHub:
=>git add .
=>git commit -m "Brief description of changes"
=>git push origin feature/your-feature-name
# Then, go to the GitHub repository and click "Compare & pull request".

## 5. Fill the Template
Our automated PR template will appear. Please check all relevant boxes:

 [x] UI matches minimalist theme.

 [x] Self-review completed.
