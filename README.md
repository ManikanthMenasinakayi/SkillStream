## About the Project
SkillStream is designed to bridge the gap between "randomly watching tutorials" and "structured learning." While YouTube hosts the world's best educational content, it lacks the structure and satisfaction of a paid course.

This platform allows users to:

Focus: Deep-work environment with zero YouTube recommendations or comments.

Track: Real-time progress bars and "Satisfaction of Completion" triggers.

Master: Domain-specific roadmaps (Web Dev, Data Science, etc.) curated by the community.
